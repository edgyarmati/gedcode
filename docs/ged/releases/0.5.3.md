## GedCode 0.5.3

- **Reviews no longer require a second subscription.** GedCode prefers a reviewer from another provider, but automatically uses a fresh independent reviewer on an available provider when the alternative cannot run, including when its subscription or quota is unavailable. Actual failing reviews still block landing.
- **Choose when to skip independent reviews.** Tell the agent to skip reviews for this change or for this local project. It infers the scope from your request and asks when unclear. Normal code checks still run, skipped review is reported explicitly, and you can turn reviews back on at any time.
- **Existing projects need a gate upgrade.** After updating GedCode, ask the agent to preview and upgrade the project's stock review gate to enable these changes. Existing gates are not silently replaced, and customized gates are preserved. Newly set-up projects get the updated gate automatically.
