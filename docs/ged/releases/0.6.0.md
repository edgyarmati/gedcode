## GedCode 0.6.0

GedCode 0.6 brings the latest upstream integration while keeping Ged's project memory, setup and independent review process.

- **Add a project to another machine.** Clone its Git remote onto a connected machine and optionally copy selected eligible ignored text files, such as environment files. The original stays on your machine. This does not copy ordinary uncommitted changes, unpushed commits or conversation history. Private repositories require access from the destination machine.
- **Work across environments.** Use transcript context from another environment and delegate tasks through peer links. Linked environments remain a beta enabled in Settings → Labs, with access controlled on each machine.
- **Keep tasks separate.** Agents can work in isolated worktrees. Side chats let you ask about a thread without interrupting it, then bring the result back.
- **Review and organise work.** Review local commits, pin or archive projects, and schedule a task to run once at a chosen date and time.
- **Keep remote work reachable.** Updated pairing and access controls accompany Linux service protection against memory pressure from agents.

The desktop release supports **macOS on Apple Silicon only**. Existing GedCode installations keep the same Sparkle signing key and in-app upgrade path. The native mobile app is not included in this release.
