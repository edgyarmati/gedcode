## GedCode 0.7.0

GedCode 0.7 brings in the latest upstream work. Ged's project memory, setup and independent review process are unchanged.

- **Pick up where you left off.** Stopped provider threads resume natively, and `/clear` starts a fresh session in the same thread. Scheduled tasks can reuse one thread and start a fresh session on each run. Your Mac stays awake while agents work.
- **A simpler first run.** The three-step wizard is now a single Welcome page. Drop a folder on the sidebar to add it as a project. Folder search matches substrings and fuzzy subsequences.
- **Your language.** Switch the interface language in Settings → General. The choices are Spanish, Chinese, Russian, Korean, Japanese, German, French and Brazilian Portuguese.
- **Pull requests in the conversation.** Add pull request comments to the chat. Composers complete `@user` and `#123` references. Watched GitHub pull requests react when a check suite completes. GitLab gains review change requests, merge request reverts and linked references.
- **Secrets stay out of chat.** Agents ask for secrets through a request instead of the transcript. You can answer with a secret provider reference, which is checked before it is saved.
- **More providers and models.** Kiro is available as an ACP provider and Claude Fable 5.2 is in the model picker. Text generators let a model API write titles, commit messages and transcript cleanup. Claude tool calls can render MCP Apps.
- **Housekeeping.** Threads that have been inactive for 7 days settle automatically, and archived threads can be deleted. Settings → Maintenance reclaims freed database space. Spreadsheet previews let you resize rows and columns. Screen readers now announce the agent's messages and steps.

The desktop release supports **macOS on Apple Silicon only**. Existing GedCode installations keep the same Sparkle signing key and in-app upgrade path. The native mobile app and T3 Connect are not included in this release.
