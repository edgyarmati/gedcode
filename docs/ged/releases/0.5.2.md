## GedCode 0.5.2

- **Upgrading from 0.4 no longer fails on some databases.** Some 0.4 databases were refused by the upgrade, and once an upgrade had failed, every later start failed too. GedCode now recognises these databases and recovers a failed upgrade on the next start, keeping your projects, threads and messages. Before recovering, it saves a backup of the database beside it in the data folder.
- **Agents write less code.** Implementers are told to look for existing code, the standard library or a small change before writing something new, and verifiers report code the task did not need so it goes back for another round.
